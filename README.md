# VCastroLab

Site do VCastroLab, grupo de pesquisa do Prof. Vinicius Silva Castro (UFMT), publicado pelo GitHub Pages em https://viniciuscastrobr.github.io

## Onde fica cada página

| Página | Português | English |
|---|---|---|
| Início / Home | `index.html` | `en/index.html` |
| Pesquisa / Research | `pesquisa.html` | `en/research.html` |
| Publicações / Publications | `publicacoes.html` | `en/publications.html` |
| Opinião / Opinion | `opiniao.html` | `en/opinion.html` |
| Sobre / About | `sobre.html` | `en/about.html` |
| Contato / Contact | `contato.html` | `en/contact.html` |

- Cores e fontes: `assets/style.css` (variáveis no topo do arquivo).
- Imagens: `assets/img/`. Banner, DNA, vírus, laboratório, molécula e rede neural vêm do Pixabay (licença livre); a tábua de frios também é do Pixabay.
- `publications.html`, `contact.html` e `opinion.html` na raiz só redirecionam os endereços antigos para as páginas novas.

## Como editar um texto

1. No GitHub, abra o arquivo da página e clique no lápis (Edit).
2. Mude só o texto entre as marcações `<p>` e `</p>` (ou `<li>` e `</li>`).
3. Clique em **Commit changes**. O site atualiza sozinho em 1 ou 2 minutos.
4. Lembre de fazer a mesma mudança na versão em inglês, dentro da pasta `en/`.

## Como publicar um artigo de opinião

1. Crie o texto do artigo (por exemplo `opiniao-1.html`, copiando `opiniao.html` como base).
2. Em `opiniao.html`, copie o bloco modelo que está comentado, troque data, título, resumo e link, e apague o aviso "em breve".
3. Faça o mesmo em `en/opinion.html` se houver versão em inglês.
